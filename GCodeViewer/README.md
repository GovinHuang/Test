# GCodeViewer - 使用 VS Code/Visual Studio 打开

## 这是什么

一个 **纯 C / Win32 API / GDI** 实现的 G 代码查看器，无需 Qt/OpenCV 等依赖。
可以直接用 Visual Studio 2022 打开 `.sln` 编译运行。

## 目录结构

```
GCodeViewer/
├── GCodeViewer.sln           # VS 解决方案
├── GCodeViewer.vcxproj       # VS 工程文件 (v143, Win32/x64)
├── src/
│   ├── gcode.h   / gcode.c   # G 代码解析器
│   ├── render.h  / render.c  # GDI 绘制模块
│   └── winmain.c             # Win32 GUI 主程序
└── sample.nc                 # 示例 G 代码
```

## 编译运行

1. 用 **Visual Studio 2022** 打开 `GCodeViewer.sln`
2. 选择 **x64 | Debug** (或 Win32)，按 F7 构建
3. 运行后菜单 **文件 → 打开 G 代码文件**，选择 `sample.nc`
4. 或在命令行：`GCodeViewer.exe sample.nc` 也能直接打开

## 支持的 G 代码

| 指令 | 说明 |
|---|---|
| G00 | 快速移动 (灰色虚线) |
| G01 | 直线插补 (红色切削 / 绿色空移) |
| G02 / G03 | 顺/逆圆弧插补 (蓝色，I/J 或 R) |
| G90 / G91 | 绝对 / 增量坐标 |
| G17 / G18 / G19 | 平面选择 (默认 XY) |
| G20 / G21 | 英制 / 公制 |
| G28 / G30 | 快速回零 |
| G81 / G80 | 钻孔循环 / 取消 |
| G92 | 设置当前位置坐标系 |
| M03 / M04 / M05 | 主轴启停 (决定是否"切削") |

## 交互

| 操作 | 作用 |
|---|---|
| 鼠标滚轮 | 以鼠标为中心缩放 |
| 中键拖拽 (或 Ctrl+左键) | 平移视图 |
| F | 自适应 Fit |
| + / - | 键盘缩放 |
| 鼠标悬停 | 状态栏显示世界坐标 |

## 渲染颜色约定

- **红色实线** — G01 切削段 (工具开启)
- **绿色实线** — G01 空移段 (工具关闭)
- **蓝色实线** — G02/G03 圆弧
- **灰色虚线** — G00 快速移动
- **橙色虚线** — Z 轴空移
- **紫色** — 钻孔切削段
- **绿色方块** — 起点标记
- **红色圆圈** — 终点标记
